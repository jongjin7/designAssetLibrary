# Sprint 2: 데스크탑 관리 화면 구성 명세 (Desktop UI Screen Specification)

Sprint 2 데스크탑 대시보드와 브라우저 확장 프로그램의 UI 구성 요소, 레이아웃 구조, 내비게이션 흐름을 정의합니다. 기능 명세([sprint2-desktop.md](sprint2-desktop.md))를 기반으로 대량 관리와 정밀 캡처를 위한 화면 사양을 구체화합니다.

Sprint 2 Desktop UI focuses on a **3-column high-performance layout** (Sidebar - Explorer - Inspector) for maximum productivity.

---

## 1. 내비게이션 구조 (Navigation Structure)

### 1.1 전체 화면 흐름

데스크탑 앱은 고정된 사이드바를 통해 주 메뉴와 폴더 구조를 탐색합니다.

```text
┌─────────────────┐
│  Desktop Shell  │
└────────┬────────┘
         │
   ┌──────┴───────┐
   ▼              ▼
Sidebar Nav      Main Content Area
   │              │
   ├─ Inbox (새항목) ├─ 에셋 그리드 (Explorer)
   ├─ 모든 에셋      ├─ 검색 결과 (Search)
   ├─ 즐겨찾기       └─ 에셋 상세 (Inspector)
   ├─ 폴더 트리
   └─ 스마트 폴더
```

### 1.2 사이드바 구성 (Sidebar Navigation)

| 메뉴 그룹 | 구성 요소 | 가용 인터랙션 |
| --- | --- | --- |
| **Workspace** | **Inbox (로컬 감시)** | Chokidar로 감지된 로컬 신규 에셋 승인 대기 목록 |
| **Library** | 모든 에셋, 즐겨찾기, 최근 항목 | 클릭 시 Explorer 그리드 필터링 |
| **Folders** | 계층형 폴더 (Max 5 Depth) | 드래그로 위치 변경, 우측 화살표로 하위 폴더 개폐 |
| **Smart Views**| 스마트 폴더 목록 | 조건 기반(예: "최근 7일 Red") 자동 갱신 목록 |

## 2. 데스크탑 앱 화면 구성 (Desktop App screens)

데스크탑 애플리케이션은 메인 대시보드를 중심으로 관리 및 설정과 관련된 다양한 전문 화면으로 구성됩니다.

### 2.1 대시보드 명세 (Library Dashboard Spec)

에셋 탐색 및 대량 관리를 위한 핵심 워크스테이션으로, 다음과 같은 지능형 기능을 포함합니다.

*   **3-Column 고성능 인터페이스**: 
    *   사이드바(탐색), 그리드(전시), 인스펙터(편집)가 유기적으로 연결된 다단 레이아웃.
    *   화면 너비에 따른 인스펙터 패널의 자동 개폐 및 그리드 최적화.
*   **지능형 폴더 및 저장 시스템**: 
    *   Max 2 Depth의 계층형 폴더 구조 및 로컬 영구 저장(LocalStorage) 동기화.
    *   드래그 앤 드롭을 통한 폴더 간 에셋 이동 및 대량 업로드 지원.
*   **반응형 전시 및 줌(Zoom) 규칙**: 
    *   순수 격자(Grid) 외에 폭포형(Masonry), 리스트(List) 전시 엔진 탑재.
    *   줌 레벨에 따른 정보 노출 자동화: 30% 이하(Visual Focus), 80% 이상(Detailed Metadata).
*   **개인화 보기 제어**:
    *   썸네일 해상도 최적화(CDN 파라미터 연동) 및 파일명/확장명/주석 표시 여부 개별 제어.
    *   하위 폴더 내용을 포함한 재귀적 에셋 수집(Flat View) 로직 제공.

#### 2.1.1 보기 설정 및 개인화 상세 (View & Personalization Specs)

사용자의 작업 흐름에 따라 갤러리의 시각적 구성과 데이터 로드 방식을 결정하는 세부 규칙입니다.

| 카테고리 | 제어 항목 | 상세 동작 및 시스템 규칙 |
| --- | --- | --- |
| **갤러리 엔진** | **보기 모드** | 1) **Grid**: 1:1 고정비 카드. 2) **Masonry**: 이미지 원본 비율 기반 가변 높이. 3) **List**: 파일 정보 중심의 한 줄 보기 |
| **렌더링 최적화** | **썸네일 품질** | 1) **Speed**: 300px 이하 저해상도 요청. 2) **Quality**: 1200px 이상 고해상도 혹은 원본 소스 요청 (Lazy-loading 강도 조절) |
| **데이터 정렬** | **정렬 방식** | 이름(가나다), 생성일(최신순), 수정일, 용량 기준 정렬 및 Asc/Desc 토글 실시간 반영 |
| **정보 가시성** | **요소별 토글** | **파일명**, **컬러 팔레트**, **확장자 라벨**, **주석(Annotation)** 등의 레이어를 개별 스위치로 제어 |
| **탐색 범위** | **하위 폴더 포함** | 활성화 시 현재 폴더 이하 모든 뎁스의 에셋을 부모 폴더 구분 없이 그리드에 일괄 나열 |

### 2.2 설정 화면 (Profile & Settings)

사용자 개인화 및 시스템 환경 설정을 관리합니다.

*   **프로필 설정**: 닉네임, 프로필 이미지 편집 및 연동 기기 관리.
*   **테마 및 개인화**: 다크/라이트 모드 고정 및 인터페이스 컬러 테마 설정.
*   **스토리지/연동**: 로컬 감시 폴더 경로 지정 및 Supabase 클라우드 싱크 상태 관리.

### 2.3 어드민 및 통계 페이지 (Admin & Statistics)

조직 관리 및 데이터 활용 현황을 모니터링합니다.

*   **팀/구성원 관리**: 협업용 공유 라이브러리 권한 제어 및 초대.
*   **사용량 통계**: 스토리지 점유율, 가장 많이 사용된 태그/컬러 분석 대시보드.
*   **활동 로그**: 에셋 변경 이력 및 시스템 이벤트 추적.

### 2.4 기타 보조 페이지

*   **도움말/가이드**: 기능 안내 및 단축키 일람.
*   **업데이트**: 릴리즈 노트 및 신규 버전 체크.

## 3. 브라우저 확장 프로그램 명세 (Browser Extension UI)

Chrome 브라우저 확장 프로그램(Nova Capture)은 팝업 및 컨텍스트 메뉴를 통해 7가지 캡처 모드를 지원합니다.

| 카테고리 | 모드 | 아이콘 | 주요 기능 및 설명 |
| --- | --- | --- | --- |
| **시각적 캡처 (Visual)** | **전체 페이지** | `Scroll` | 페이지 하단까지 자동 스크롤하며 합성 캡처 |
| | **보이는 영역** | `Monitor` | 현재 뷰포트 영역 즉시 캡처 |
| | **영역 선택** | `Crop` | 크로스헤어로 직접 지정한 영역 캡처 |
| | **요소 캡처** | `MousePointer` | 마우스 오버된 DOM 요소를 자동 인식하여 캡처 |
| **리소스 추출 (Extraction)** | **이미지 추출** | `Images` | 페이지 내 모든 이미지(img, svg)를 리스트화하여 선택 저장 |
| | **반응형 캡처** | `Smartphone` | Breakpoints(Mobile/PC)별 세트 일괄 캡처 |
| **큐레이션 (Curation)** | **URL 북마크** | `Link` | 스크린샷 없이 메타데이터(URL)만 저장 |

#### [확장 프로그램 인터랙션 규칙]
*   **Access**: 브라우저 툴바 팝업 및 웹페이지 내 우클릭(Context Menu) 접근.
*   **Workflow**: 캡처 즉시 데스크탑 앱의 **Inbox**로 백그라운드 전송.

## 4. 수락 기준 (Acceptance Criteria)

- [ ] **[3열 레이아웃]** 1280px 이상에서 레이아웃 깨짐 없이 3열 유지.
- [ ] **[지능형 기능]** 줌 레벨에 따른 텍스트 숨김 로직이 100ms 이내 반응.
- [ ] **[7종 캡처]** 브라우저 확장 프로그램에서 URL 북마크를 포함한 7종 모드가 정상 작동.
- [ ] **[실시간 동기화]** 캡처 데이터가 데스크탑 상단 Inbox에 3초 이내 노출.
